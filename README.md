# Sensory Analysis



Sensory analysis is a scientific discipline that uses the five human senses (sight, smell, touch, taste, and hearing) to measure, analyze, and interpret reactions to products.



This field is widely used in the food, beverage, cosmetics, and hygiene industries because it allows companies to evaluate product characteristics that directly influence consumer acceptance. Through sensory analysis, it is possible to identify differences between products, assess the quality of raw materials, and monitor production consistency over time.



There are several types of sensory analysis, each serving a different purpose. Discriminative tests determine whether noticeable differences exist between samples. Descriptive tests identify and characterize a product's sensory attributes. Affective tests measure consumer preference and satisfaction.



**This application focuses on discriminative tests.**
